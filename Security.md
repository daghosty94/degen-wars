# Security Policy

## Project Status

Degen Wars is currently under active development and has not completed a formal security audit. The project should not be used with valuable wallets, production credentials, or mainnet assets without independent security review and testing.

## Reporting a Vulnerability

Please do not publicly disclose suspected vulnerabilities through GitHub Issues.

To report a security concern, contact:

**Hector Tavarez**  
Email: htavarez94@yahoo.com

Please include:

- A description of the vulnerability
- The affected file or component
- Steps to reproduce the issue
- The potential security impact
- Any recommended remediation

## Sensitive Information

The repository is configured to exclude sensitive data, including:

- Private keys
- Wallet keypairs
- Seed phrases
- Environment files
- API credentials
- Token checkpoint files
- Local configuration files
- Build artifacts and dependencies

## Supported Version

Only the latest version of the `main` branch is currently supported.

## Responsible Disclosure

Please allow reasonable time to investigate and remediate reported vulnerabilities before publicly disclosing them.
